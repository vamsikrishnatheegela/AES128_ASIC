# AES-128 Cryptographic Accelerator ASIC

## Overview

This project implements an iterative AES-128 encryption accelerator in Verilog and demonstrates a complete RTL-to-GDSII ASIC implementation flow.

## Toolchain

- Verilog HDL
- Verilator
- Yosys
- OpenROAD
- OpenSTA
- Magic
- Netgen
- Xyce

## Directory Structure

- rtl/
- tb/
- scripts/
- constraints/
- synthesis/
- layout/
- reports/
- results/
- docs/

## Target

- AES-128 Encryption
- Iterative Architecture
- ASIC Implementation
- 100 MHz Target Frequency
